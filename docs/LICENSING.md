# Licensing and upstream attribution

This repository is a Rust port of the public [Serenity Dojo `cashback-rewards`](https://github.com/serenity-dojo/cashback-rewards) example.

The port was based on the behavior, architecture, specifications, API contract and database schema visible in the upstream `section-13/solution` branch at commit `1f8e0083cf61dbb1c852e3140b9fb56b8398cc0a`.

During review, no `LICENSE` file was present in that branch's repository tree. This repository therefore does **not** declare an open-source license for the port. Before publishing it under a specific license, review the upstream repository's applicable copyright and licensing terms and obtain any permissions that may be required.

The port intentionally contains an explicit upstream attribution and a porting-notes document so the relationship remains visible.
