# API contract

The executable OpenAPI document is generated at `/api-docs/openapi.json`.

The current implemented endpoints are:

- `POST /api/merchants`
- `POST /api/categories`
- `PUT /api/categories/default-rate`
- `POST /api/purchases`
- `GET /api/customers/{customerId}/cashback`
- `GET /api/products/{productCategory}/cashback-total`
